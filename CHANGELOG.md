# Changelog

## Unreleased — public source baseline

- Native macOS setup, file-review, and backup-progress pages.
- Recursive duplicate comparison by filename, extension, and exact size.
- Review filters, multi-row selection, and checked-file inclusion.
- SHA-256 verification, conflict preservation, staged copies, and cancellation.
- Percentage, speed graph, estimated time, elapsed time, and current-file progress.
- Optional five-minute repeat backups for a confirmed file selection.
- App logo and Finder/Dock icon, with packaged-icon validation and local Finder registration refresh after builds.
- MIT license, user and contributor documentation, community and security policies, issue/PR templates, and macOS CI.
- Explicit macOS 13 deployment target and table construction compatible with that target.
